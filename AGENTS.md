# AGENTS.md

This is a React/Vite application backed by Supabase.

- Frontend source: `src/`
- Supabase client and app API: `src/api/supabaseClient.js`
- Database schema and RLS: `supabase/migrations/`
- Edge Functions: `supabase/functions/`
- Local secrets: `.env.local` (never commit it)

Run `npm run build`, `npm run lint`, and `npm run typecheck` before shipping changes.
